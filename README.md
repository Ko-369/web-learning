# web-learning

Web 前端 HTML 学习练习仓库，用于记录学习 Demo 与学习笔记。

## 📖 项目简介

本仓库用于存放个人 Web 前端学习练习代码，目前主要以 **HTML 基础知识** 为主。

项目按照不同知识点划分独立文件夹，每个目录包含对应的 HTML 练习案例，部分章节配套 `study.md` 学习笔记，用于记录学习过程，方便后续复习与知识回顾。

后续将持续补充 **CSS、JavaScript** 等前端相关学习内容。

## 🚀 本地运行

### 1. 克隆仓库

```bash
git clone https://github.com/Ko-369/web-learning.git
```

### 2. 进入项目目录

```bash
cd web-learning
```

### 3. 使用 VS Code 打开项目

```bash
code .
```

也可以直接使用文件管理器打开项目目录。

### 4. 运行 HTML 文件

本项目目前主要为静态 HTML 页面，因此 **不需要安装额外依赖**。

直接使用浏览器打开对应的 `.html` 文件即可查看效果。

例如：

```text
demo3_跳转/index.html
```

也可以在 VS Code 中安装 **Live Server** 插件，通过本地服务器运行 HTML 页面。
