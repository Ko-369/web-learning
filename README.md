# web-learning
Web前端HTML学习练习仓库，记录学习demo与笔记

## 📖 项目简介
本仓库用于存放个人前端学习练习代码，主要以HTML基础练习为主。
按知识点划分独立文件夹，部分案例配套 `study.md` 学习笔记，用来留存学习过程、方便后续复盘回顾。
后续会持续补充 CSS、JavaScript 等前端相关练习demo。
