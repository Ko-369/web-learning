表单使用场景很局限，使用频次比较低，常用于登录页面、注册页面、搜索功能。


input标签：在网页中显示手机用户信息的表单效果，如：登录页、注册页

input标签可以通过type属性值的不同，展示不同效果

input标签不会自动换行

input标签的type属性值：
            ┌─────────┬──────────────┬─────────────────────────────────────┐
            │ 标签名   │ type属性值   │ 说明                                │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ text         │ 文本框，用于输入单行文本              │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ password     │ 密码框，用于输入密码                 │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ radio        │ 单选框，用于多选一                   │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ checkbox     │ 多选框，用于多选多                   │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ file         │ 文件选择，用于之后上传文件           │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ submit       │ 提交按钮，用于提交                   │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ reset        │ 重置按钮，用于重置                   │
            ├─────────┼──────────────┼─────────────────────────────────────┤
            │ input   │ button       │普通按钮，默认无功能，之后配合js添加功能 │
            └─────────┴──────────────┴─────────────────────────────────────┘


常用属性：
        1.placeholder：  占位符，提示用户输入内容的文本。
        2.name： 分组
            ·有相同name属性的单选框为一组，一组中同时只能有一个被选中
            ·name属性对于单选框有分组功能
            
        3.checked 默认选中


多文件选择：multiple属性
file属性默认一次只能上传1个文件，如果要上传多个文件，需要在后面加multiple

from标签：
        1.如果要提交或重置功能能用，前提要有表单域标签。
        2.使用方法：用form标签把表单标签一起包裹起来即可。

注意：1.谷歌浏览器中button默认是提交按钮。
      2.button标签是双标签。


select下拉表单标签
select标签组成：select标签做下拉标签的整体，option标签做下拉菜单的每一项，select包裹option，设置默认选中需要给option设置selected属性。


文本域标签：textarea，双标签。


label标签：1.使用场景：常用于绑定内容与表单标签的关系
           2.使用方法：方法1.
