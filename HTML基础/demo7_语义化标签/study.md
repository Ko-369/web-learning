div标签和span标签和不加任何标签的普通文字效果一样，效果后期通过css进行添加

div标签独占一行，span标签不会独占一行。


做手机端网络常用以下有语义的标签，通常没有肉眼的效果，通常通过css进行效果配置。

┌──────────┬────────────┐
│ 标签名   │ 语义       │
├──────────┼────────────┤
│ header   │ 网页头部   │
├──────────┼────────────┤
│ nav      │ 网页导航   │
├──────────┼────────────┤
│ footer   │ 网页底部   │
├──────────┼────────────┤
│ aside    │ 网页侧边栏 │
├──────────┼────────────┤
│ section  │ 网页区块   │
├──────────┼────────────┤
│ article  │ 网页文章   │
└──────────┴────────────┘
